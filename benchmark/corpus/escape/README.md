# 逃逸用例（escape cases）

**目的**：sanity check 评审器是否还能工作。每次 benchmark run 结束，escape 的 Elo rating 必须 **< 1250**（初始 1500，差 250+）。否则说明评审器在该次 run 中已"失智"，整个 run 作废。

## 什么叫"故意写坏"

| 类型 | 特征 |
|------|------|
| **套话堆砌** | 观点模糊、全是"值得深思"/"不容忽视"/"在这个时代"类陈词 |
| **论据缺失** | 论断无例、无数据、无对比、无边界讨论 |
| **结构崩坏** | 每段讨论不同话题、无递进、前后矛盾 |
| **AI 味拉满** | "首先"/"其次"/"总而言之"频繁、罗列式回答、结尾强行升华 |

**不是"AI 生成的文"**，因为好的 skill 产出也是 AI 生成的。差在**质量**，不在**来源**。

## 制作建议

- 可以拿 skill 早期失败产出改改（把亮点删掉，加套话）
- 可以手写一篇"典型 CSDN 水文"作为样板
- 每篇字数建议 1500-2500（不要太短也不要超长）
