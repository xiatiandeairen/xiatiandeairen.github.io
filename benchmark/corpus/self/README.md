# 博主本人 历史语料

**角色**：自我参照。skill 必须至少打平博主本人水准，否则它不如博主直接写。

## 选文标准

- 5 篇博主认可的历史文
- 1 篇博主认为"本人一般水位"的历史文（供 Pilot 作 golden pair "好 vs 差"）
- 分布：至少各 1 篇覆盖"思辨随笔 / 信息聚合 / 工程深度"

## 文件命名 / 模板

同 `ruanyifeng/README.md`，`author_rating` 字段严格：

- `high`：博主本人满意、愿意再写
- `reference`：一般水准代表作
- `low`：本人觉得勉强的（Pilot 要用）

## 来源

从 `src/content/notes/*.md` 手动挑选，**去掉 frontmatter 和评论区**，只保留正文。
